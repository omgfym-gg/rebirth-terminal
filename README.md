# 轉生終端

像素風回合制神魔 RPG。死亡不是結束：每一次死亡，靈魂都會被送進「靈魂結算終端」，帶著前世的因果轉生。

與《神魔社畜模擬器：靈魂結算終端》共用同一個世界觀。

## 怎麼玩

用手機瀏覽器打開 GitHub Pages 網址即可，不需要安裝。存檔存在瀏覽器裡。

## 第一版內容

- 回合制格子戰鬥（7×9），三層地城，最下層有首領「無臉典獄長」
- 三種生命形態：人類、神使、惡魔
- 兩種信仰領域：索爾（落雷、水面導電）、洛基（幻影、混亂）
- 死亡後變成靈魂：可以被救援、被敵人搶魂，或飄向裂縫逃走
- 靈界（結算終端）：因果紀錄、靈魂商店、常客劇情（張醫師、阿凱）
- 轉生時繼承一個前世技能，技能會依新形態變異
- 前世回響：英雄雕像、殘魂、懸賞令
- 第七世揭曉隱藏真相（每個存檔隨機一種）

## 檔案

- `index.html`、`style.css`：頁面與樣式
- `js/data.js`：形態、技能、敵人、地圖、常客劇情、隱藏真相
- `js/sprites.js`：佔位用的像素圖
- `js/battle.js`：戰鬥系統
- `js/main.js`：遊戲流程與存檔
