# 轉生終端

像素風回合制神魔 RPG。死亡不是結束：每一次死亡，靈魂都會被送進「靈魂結算終端」，帶著前世的因果轉生。

與《神魔社畜模擬器：靈魂結算終端》共用同一個世界觀。

## 怎麼玩

用手機瀏覽器打開 GitHub Pages 網址即可，不需要安裝。存檔存在瀏覽器裡。

## 目前內容

- 戰鬥是「一筆紅線」：三位神魔輪流上場，照每招的畫法（直線、衝刺、自由線、折線、畫圈、連點）在戰場上畫，線穿過隊友發動天賦，同一回合的線交叉就是紅線交會
- 一世一座十層的塔：第 5、10 層魔王（考績審判官、典獄長本尊），第 3、6、9 層精英（無臉典獄長、追殺者）；越後面的世，塔越強
- 轉生三條路：升仙（只能選神族）、入魔（只能選魔族）、為人（兩族都能選、神器邪物都能穿，生命少一成五）；每條路每一世隨機給三位
- 隊伍 = 今世的你 + 兩位前世之影（死過的每一世，停在死前的等級、穿著死前的裝備）；第一世由終端派遣兩位同事
- 13 位可玩神魔，每位 3 招＋被動＋天賦；等級每位各自永久保留（目前升級只加生命）
- 裝備：兵器、法寶兩格，神器給神族、邪物給魔族、專屬兵器只有本人能用；精英、魔王三選一掉落（只掉今世穿得了的），轉生時清空；前世之影穿著死前的裝備
- 層與層之間的岔路二選一：營火、血祭壇、迷途的靈魂、上鎖的箱子、靈泉
- 靈界（結算終端）：因果紀錄、靈魂商店（生命、朱砂、墨水）、常客劇情（張醫師、阿凱）、靈魂本質（秩序↔混沌）與因果債
- 第七世揭曉隱藏真相（每個存檔隨機一種）

## 檔案

- `index.html`、`style.css`：主遊戲頁面與樣式
- `js/redline.js`：一筆紅線戰鬥模組（神魔、敵人、裝備資料都在這裡），主遊戲和 `redline.html` 共用
- `js/main.js`：遊戲流程與存檔（存檔 `rebirth-terminal-save-v2`，舊版存檔不轉）
- `js/data.js`：轉生三條路、樓層、岔路事件、常客劇情、隱藏真相
- `js/jobs.js`：60 位神魔的設定（目前用到角色出處 `ORIGINS`）
- `js/sprites.js`：像素圖
- `redline.html`：一筆紅線單獨試玩（自選三位、無限爬樓）
- `card.html`、`side.html`、`cowar.html`：已經不用的舊戰鬥試玩
- `yuelao.html`：月老像素動畫測試頁；素材在 `assets/yuelao/`
- `tools/sprite_pipeline.py`：把 Gemini 白底像素圖去背、縮成真正的像素格、拼成 spritesheet
  - 格子整齊的原圖：`--frame 49 78`（自動偵測像素格大小）
  - Gemini 補的動作圖格子不整齊：`--height 76` 等比例縮到這個高度
  - `--merge-small` 小碎片併進角色；`--flip 1` 翻轉第 1 格；`--holes` 線圈圍住的白洞也去背（只給甩紅線用，不然白鬍子會被挖掉）
  - 月老實際用的指令：walk/punch `--height 76`，cast `--height 76 --merge-small --holes`，hurt `--height 74 --flip 1`
